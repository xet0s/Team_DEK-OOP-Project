# Team_DEK-OOP-Project
Hitit University Computer Engineering Department Object Oriented Programing Lecture Final Project

This project is a backend application developed for the "Video Platform Management System" assignment given within the scope of the Hitit University Object-Oriented Programming course.

## Technologies Used in the Project
Language: Python 3.x

Libraries: PyQt6, peewee, bcrypt

Paradigm: Object-Oriented Programming (OOP)

Tools: MySQL, Git, GitHub
